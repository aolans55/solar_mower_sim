## 1. 課題の概要と目的
- 背景: ソーラー発電所の除草は人手・コスト負担が大きく、パネル架台周りは機械化しにくい。業務でこの用途の草刈り機開発を予定しており、その制御系のプロトタイプを仮想環境で検証した。
- 目的: 履帯ロボットが (1) 自然言語の指示で動き、(2) パネル列に平行に走り、(3) 凸凹地面を乗り越えながら直進する、の 3 機能を ROS 2 + Gazebo で実現する。

## 3. 工夫した点
1. **LLM を制御ループに入れない安全設計** — LLM は「何をするか」の JSON だけを生成し、スキーマ検証と数値クランプを通してから状態機械に渡す。LLM の誤出力・遅延がそのまま駆動に影響しない。実機でも同じ構成が使える。
2. **架台の横梁を LiDAR の基準線に** — 傾斜パネルは LiDAR 平面に入らないため、架台の横梁 (連続した直線構造) を追従対象とした。RANSAC により支柱や草などの外れ値に頑健。
3. **履帯のスリップ補正** — 履帯は旋回時にスリップし進路がずれるため、オドメトリでなく IMU ヨー角で方位を保持。ピッチ角が大きいときは自動減速。
4. **ROS 非依存の制御ロジック** — controllers.py は pytest で単体テスト済み。シミュレータなしで動作検証できる。
5. **ワールドの自動生成** — パネル列・不整地をスクリプト生成し、列数や凸凹の大きさをパラメータで変えて再現実験できる。
